**01** 퍼셉트론은 신호를 입력으로 받아 하나의 신호를 출력하는 기계로, (**인공신경망**)의 기원이 되는 알고리즘입니다.

**02** 퍼셉트론은 입력 → 가중치 → 가중합 → (**활성화 함수**) → 출력의 내부 과정을 거칩니다.

**03** (**선형 분리**)은(는) AND, OR 연산과 같이 직선 하나로 데이터들이 두 개의 그룹으로 나누어지는 것을 의미합니다.

**04** 역전파를 수행할 때 출력층에서 멀리 떨어진 층에서는 기울기가 급속히 작아지는 (**기울기 소멸**) 문제와 기울기가 너무 커지는 (**기울기 폭주**) 문제가 발생해 학습력이 떨어졌습니다.

**05** (**사전 학습**)란(이란) 선행학습이라고도 부르며, 다층 퍼셉트론에서 가중치와 편향을 잘 초기화시키는 방법을 뜻합니다.

06 딥러닝은 다수의 은닉층을 가진 인공신경망을 사용하여 머신러닝 학습을 수행하는 것으로, (심층신경망)라고도(이라고도) 합니다.

(참고: DNN 또는 Deep Neural Network)

**07** (**편향**)은(는) 가중합에 더하는 상수로, 하나의 뉴런에서 활성화 함수를 거쳐 최종적으로 출력되는 값을 조절합니다.

**08** (**활성화 함수**)은(는) 인공신경망에서 각 뉴런이 입력을 받아 출력을 계산하는 함수입니다.

**09** (**탄젠트 하이퍼볼릭(tanh)**) 함수는 시그모이드 함수와 유사하지만, -1~1의 값을 가지면서 데이터의 평균이 0이라는 점이 다릅니다.

**10** (**ReLU(렐루)**) 함수는 x가 음의 값을 가지면 0을 출력하고, 양의 값을 가지면 x를 그대로 출력합니다.

**11** (**정규화**)은(는) 데이터의 범위를 사용자가 원하는 범위로 제한하는 것입니다.

**12** (**배치 정규화**)란(이란) 딥러닝에서 학습 속도를 빠르고 안정적이게 만드는 것을 뜻합니다.

**13** (**오차 역전파**)은(는) 오차(예측값과 실제값의 차이)를 역방향으로 전파시키면서(출력층 → 은닉층 → 입력층) 가중치를 업데이트하는 것입니다.

14 (DNN)은(는) 심층신경망이라고도 부르며, 딥러닝에서 가장 기본으로 사용하는 인공신경망입니다.

(참고: 문맥에 따라 '다층 퍼셉트론(MLP)'이 답일 수도 있으나, 심층신경망이라는 명칭과 짝을 이루는 약어는 DNN이 가장 적절해 보입니다.)

**15** (**RNN(순환 신경망)**)은(는) 시계열 데이터와 같이 시간적으로 연속성이 있는 데이터를 처리하기 위해 고안된 인공신경망입니다.

**16** CNN의 신경망 구조 중 (**풀링(Pooling)**)은(는) 합성곱층의 출력 데이터(특성 맵)를 입력으로 받아 출력 데이터인 활성화 맵의 크기를 줄이거나 특정 데이터를 강조하는 용도로 사용됩니다.

17 (임베딩)은(는) 단어를 벡터로 표현하는 방법입니다.

(참고: 단어 임베딩)

**18** (**워드투벡터(Word2Vec)**)란(이란) 비슷한 콘텍스트(context)에 등장하는 단어들은 유사한 의미를 지닌다는 이론에 기반하여 단어를 벡터로 표현해 주는 기법입니다.

**19** 다음 중 역전파에 대한 설명으로 올바른 것은?

- **정답: ⑤ 신경망의 오차를 출력층에서부터 입력층으로 거꾸로 전파시켜 각 층의 가중치와 편향을 업데이트한다.**
    

**20** 다음 중 무엇을 학습하기 위한 방법으로 역전파가 고안되었는지 **모두** 고르시오.

- 정답: ② 가중치, ⑤ 편향
    
    (역전파는 신경망의 파라미터인 가중치(Weight)와 편향(Bias)을 최적화하기 위해 사용됩니다.)
