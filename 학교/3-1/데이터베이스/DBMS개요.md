## 대표DB

- MySQL
- Oracle
- SQLLite

### 데이터의 무결성(integrity)

- 제약 조건(constraint)에 따라 무결성 보장

### 데이터의 독립성

- 데이터 베이스의 크기나 저장소가 변경되어도 기존 응용 프로그램에 영향을 미치지 않는다
- DB와 응용프로그램은 독립적으로 동작한다

## 보안

- 소유자와 허가된 사용자만 이용가능

## 데이터 중복 최소화

- 동일한 데이터가 여러곳에 저장되는 것을 방지함

## 데이터의 안전성 향상

- 백업 및 복원 기능 제공
- 데이터 손상시 복구 가능
