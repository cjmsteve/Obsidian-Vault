# 인류사

## 도구의 중립성

기술은 중립적이지 않다. 기술은 인간의 가치관을 반영하며, 동시에 인간의 삶의 방식을 강제함

라디오 - 동시성 - 모임 - 선전(프로파간다),선동

손의 자유 - 멀티테스킹

에너지원의 발견

석탄 석유 원자력 데이터

### 1차 산업혁명

기계화의 시작(18세기 후반) 영국시작

-증기기관과 석탄의 결합이 가내수공업을 공장제 기계 공업으로 전환

- 핵심동력 - 인간과 가축의 근력을 기계가 최초로 데체
- 산업구조의 변화 - 가내수공업_> 기계공업
- 도시화
- 새로운 인간상

### 2차 산업혁명

핵심동력 - 전기 + 석유, 컨베이어밸트 조립 라인 생산방식 혁명

사회적 영향

- 자본주의의 성장
- 대륙간 소통과 이동 급증
- 전문 경영인과 거대 기업의 탄생

### 3차 산업혁명

정보화와 자동화

핵심동력 - 컴터 인터넷 반도체 디지털 기반의 지식 정보 사회 진입

자동화의 확산 - 생산성의 비약적 향상

가상 세계의 탄생 - 물리적공간을 초월한 사이버페이스 등장, 정보가 자본보다 중요한 가치로 부상

새로운 인간상 - 컴퓨터를 다루는 화이트칼라,전 세계와 연결된 디지털 노마드 탄생

4차 산업

초연결 초인공지능

핵심동력 - 인공지능, 빅데이터, 사물인터넷( IoT )

```
    -현실과 가상의 경계가 소멸
```

사회적영향

- 자율성 - 기계의 자기학습
- 초연결 사회
- 지적 노동
