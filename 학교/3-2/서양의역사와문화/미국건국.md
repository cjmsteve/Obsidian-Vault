# 서양의역사와 문화

## 미국의 탄생과 건국 초기

식민지시대부터 건국까지 - 정치 사회 종교적 관점으로 살펴보는 미국 문화의 기원

새로운 대륙으로의 여정

- 1607년 제임스타운 : 버지니아 회사의 경제적 이익을 위해 설립된 영국 최초의 영구 정착지, 담배 농업
- 1620년 플리머스 : 종교적 박해 → 청교도들이 메이플라워호 타고 도착, 신앙 공동체 건설 목표

공통점 : 미국의 물질적 번영과 도덕적 사명감이라는 양축을 형성

청교도 내에 있는 분리주의자들이 네덜란드 통해 미국으로 이동

제임스타운

- 경제적 원인 : 황금 발견, 아시아로 통하는 무역로 개척
- 자본의 역할 : 주식회사를 통해 민간 투자를 유치하고 이윤 창출을 목표로 함
- 지정학적 원인 : 스페인의 독점을 막고 영국 세력 확장을 위함
- 사회적 원인 : 영국 내부의 인구증가 원자재부족 등등
- 인물 : 포카혼타스, 존 롤프(담배 농업 성공)

1619 년 분기점

- 시민의회 : 자치 정부의 초석
- 아프리카 노예 수출입 : 플랜테이션 경제의 시발점

같은해 같은 장소에서 민주주의와 노예제도가 시작됨 (상반된 역사)

### 1620년 플리머스 -> 메이플라워호로 횡단

메이프라워 서약 : 공동의 이익을 위해 평등하고 공정한 법률을 제정하며, 모두 자발적으로 복종하고 협력
-> 권력의 강요 없이 자발적 합의(사회계약)로 정부를 구성한 미국 최초의 문서

첫겨울에 여러 요인으로 이주민 절반 이상이 사망

스콴토와 왐파노그아의 도움

영어에 익숙한 스콴토의 도움
- 옥수수 재배법
- 생선을 거름으로 사용하는 방법
- 야생 동물 사냥법

1621년 가을 추수감사제의 유래

1630 청교도 대이주
- 아르벨라호 선상 설교 : 언덕 위에 도시 - 존 위스럽
- 칼뱅주의 : 근면성, 직업관, 자본주의 정신, 공동체 의식 형성
  -> 예정설

칼뱅주의가 미국에 남긴 유산
- 자본주의정신
- 민주주의정신
- 도덕적공동체주의

1692년 세일럼 마녀재판
