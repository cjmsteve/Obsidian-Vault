# 3장 프로젝트 계획과 관리

## #과제 과제 1
-> ai를 이용한 프로젝트 계획
-> WBS
-> 계획서 제출
-> 9/30까지



소프트웨어 공학 과목 과제로 제출할 [GPS 기반 땅따먹기 모바일 앱] 개발 프로젝트 계획서를 작성해줘.

다음 항목을 반드시 포함해서 체계적으로 작성해줘:

1. 프로젝트 개요 (목적, 주요 기능, 개발 환경 및 기술 스택)
2. 팀 구성 및 역할 분담 (팀원 [3]명 기준)
3. 추진 일정 및 WBS (Work Breakdown Structure)
   - WBS는 단계(Phase) -> 대분류 -> 중분류/세부 작업 형태의 계층 구조로 작성할 것
   - 각 작업별 예상 소요 기간(주 차)과 담당 역할 명시
   - 요구사항 분석, 설계, 구현, 테스트, 배포/보고서 작성 등 소프트웨어 공학의 표준 수명주기를 반영할 것
4. 위험 관리 계획 (예상 위험 요인 2~3가지 및 대응 방안)
5. 애자일 방법에 8주 과정기준
