# 소프트웨어

#### 소프트웨어

- 개념적이고 무형적
- 재발, 운용, 보수에 필요한 정보들도 포함

복잡성, 순응성, 변경성, 비가시성

종류

- 주문형 소프트웨어
- 패키지 소프트웨어
- 임베디드 소프트웨어

#### 소프트웨어 개발

명세화 → 구현 → 검증 → 유지보수

특징

- 명세화 어려움
- 재사용 어려움
- 예측 어려움
- 유지보수 어려움
- 고품질 어려움

#### 소프트웨어의 위기

수요가 급격히 증가하고 그 복합성이 증가 하여 기본 방법이 충분치 않음

#### 소프트웨어 공학

#### 소프트웨어 공학의 주제

- 단계적 프로세스 : 정해진 절차를 따라 작업 ( 분석→ 설계 → 구현 → 테스팅)
- 품질보즈
- 프로젝트관리 : 게획(타당성 검토, 시장성 조사) → 자원 관리 → 리스크관리 → 프로젝트 수행과 모니터링
