
## 💻 컴퓨터 구조 및 기억장치 정리

### 1. 주기억장치 (Main Memory)

#### **ROM (Read Only Memory)**

- **Mask ROM**: 제조회사에서 내용 기록, **내용 변경 불가**
	
- **PROM (Programmable ROM)**: **한 번 기록 가능**
    
- **EPROM (Erasable PROM)**: **자외선을 이용**하여 지우고 쓰기 가능
    
- **EEPROM (Electrically EPROM)**: **전기적인 성질을 이용**하여 지우고 쓰기 가능
    

#### **RAM (Random Access Memory)**

- **SRAM (Static RAM)**: 소용량의 **캐시 메모리** 사용, **고가, 고속**
    
- **DRAM (Dynamic RAM)**: **대용량, 저가, 저속**, **주기적인 충전(리프레시)**이 필요하며, 재충전 회로가 필요
    

---

### 2. CPU (Central Processing Unit) 및 레지스터

- **ALU (Arithmetic Logic Unit)**: 산술 논리 연산 장치
    
- **AC (Accumulator)**: 누산기
    
- **IR (Instruction Register)**: 명령어 레지스터
    
- **MAR (Memory Address Register)**: 기억장치 주소 레지스터
    
    - 프로그램 카운터(pc)에 저장된 명령어가 시스템 주소 버스로 출력되기 전에 **반드시 거쳐야 하는 임시 주소 레지스터**
        
- **pc (Program Counter)**: 프로그램 카운터
    
    - 다음에 **인출할 명령어 주소**를 저장
        
- **MBR (Memory Buffer Register)**: 기억장치 버퍼 레지스터
    
    - 기억장치에 쓰거나/읽혀진 데이터를 **일시적으로 저장**하는 레지스터
        

---

### 3. 보조 기억장치 (Secondary Storage)

#### **디스크 접근 시간 (Disk Access Time)**

- **탐색 시간 (Seek Time)**: 데이터를 읽고 쓰기 위해 지정된 **실린더**까지 헤드가 이동하는 데 걸리는 시간
    
- **검색 시간 (Search Time)**: 특정한 **섹터**가 헤드에 도달하는 데 필요한 시간 (회전 지연 시간)
    
- **전송 시간 (Transmission Time)**: 섹터와 **주기억장치** 간에 데이터를 전송하는 데 걸리는 시간
    

---

### 4. 기억장치 특성

#### **물리적 특성**

- CPU가 기억장치에 데이터를 쓰거나/읽기로부터 데이터를 읽는 동작
    
- **순차 접근**: 순서대로 접근 (예: 카세트)
    
- **직접 접근**: 주소를 이용해 직접 접근 (예: 디스크, CD-ROM)
    

#### **엑세스 속도 (Access Speed)**

- 단위 시간당 데이터를 읽고/쓸 수 있는 능력 (클수록 고성능)
    
- 계산: 엑세스 시간1​×워드 수
    
- 단위: Accesses per second 또는 **MB/s** (메가바이트/초)
    
- **엑세스 시간**: 읽기/쓰기로부터 데이터 엑세스가 완료되는 데 걸리는 시간 (**빠를수록 좋다**)
    

#### **전송 단위**

- **CPU**가 한 번에 데이터를 읽거나/쓰는 비트 수: **워드(Word)**
    
- **주기억장치** 전송 단위: **블록**
    
- **보조기억장치** 전송 단위: **블록**
    

#### **주소 지정 단위**

- 기억장치에 저장되는 데이터의 **최소 단위**: **비트** (대부분 워드나 바이트 단위로 지정)
    
- 주소 버스 수 (A)와 주소 지정 가능한 기억 장소 수 (N)의 관계: 2A=N
	

#### 접근 속도 (Access Speed)

- 단위: 초당 접근 횟수 (**Accesses per second**) 또는 **MB/s** (클수록 좋다)
    
- **전송 단위 (Transfer Unit)**: CPU가 한 번에 데이터를 읽거나/쓰는 비트 수 (**word**), **주기억장치-블록단위**, **보조기억장치-블록단위**
    
- **주소 지정 단위**: 기억장치에 저장되는 데이터의 최소 단위 (**비트**), **주소 버스 수 A와 주소 지정 단위 N의 관계**: 2A=N
    
    - **A**는 주소 버스 개수, **N**은 주소 지정 가능한 기억 장소 개수
        

#### 엑세스 시간 (Access Time)

- 엑세스 시간 = 읽기/쓰기로부터 데이터 엑세스가 완료되는 데 걸리는 시간
    
- **빠를수록 좋다** (클럭 속도, CPU 처리 속도에 직접 영향을 미침)
	

## 기억장치 종류, 구성 및 용량 계산

### 1. 기억장치 분류 및 특징

- **내부 기억장치 (Internal Memory)**:
    
    - **종류**: 레지스터, 캐시 메모리, 주기억장치(RAM/ROM).
        
    - **특징**: CPU가 **직접 엑세스**하며 **빠른 속도**를 가짐.
        
- **외부 기억장치 (External Memory)**:
    
    - **종류**: 디스크(Disk), SSD, CD-ROM 등.
        
    - **특징**: **기억장치 컨트롤러**를 통해 접근하며 **느린 속도**를 가짐.
        
- **주기억장치 (RAM)**:
    
    - 읽기/쓰기가 가능하며 휘발성(Volatile) 특징을 가짐.
        

### 2. 1K×8 RAM 칩과 제어 신호

- **용량**: 1K×8 ($2^{10}$개 주소 × 8비트)
    
- **주소 버스**: 1K=210 이므로 **10 비트** 필요.
    
- **데이터 버스**: 한 번에 8 비트를 처리하므로 **8 비트** 필요.
    
- **제어 신호**:
    
    - **CS (Chip Select)**: 0일 때 칩 선택 (동작), 1일 때 비선택.
        
    - **RD (Read)**: 0일 때 읽기, 1일 때 비동작.
        
    - **WR (Write)**: 0일 때 쓰기, 1일 때 비동작.
        
    - **읽기 동작**: CS=0,RD=0,WR=1
        
    - **쓰기 동작**: CS=0,RD=1,WR=0

## 컴퓨터 시스템 핵심 구조 및 동작

### 1. CPU와 기억장치 연결 (CPU and Memory Connection)

- **주소 버스 (Address Bus)**: **CPU** → **기억장치** (단방향)
    
    - CPU가 읽거나 쓸 **기억장치 주소**를 지정하여 보냄.
        
- **데이터 버스 (Data Bus)**: **CPU** ↔ **기억장치** (양방향)
    
    - **읽기 동작**: 기억장치의 **데이터**가 CPU로 전송.
        
    - **쓰기 동작**: CPU의 **데이터**가 기억장치로 전송.
        
- **제어 버스 (Control Bus)**: **CPU** → **기억장치** (주로 단방향)
    
    - **기억장치 읽기/쓰기 신호**, 인터럽트 신호 등을 보냄.
        

#### **기억장치 읽기 동작 시간 (Read Cycle)**

- 기억장치에 **주소**를 보낸 후 → CPU가 **데이터**를 받을 때까지 걸리는 시간.
    

#### **기억장치 쓰기 동작 시간 (Write Cycle)**

- CPU가 **주소와 데이터**를 보낸 후 → 기억장치에 저장 완료될 때까지 걸리는 시간.

### 2. CPU 내부 구조 및 명령어 사이클

#### **CPU 내부 레지스터의 역할**

| 레지스터                   | 역할                             |
| ---------------------- | ------------------------------ |
| **PC (프로그램 카운터)**      | 다음에 인출할 **명령어 주소**를 저장.        |
| **AC (누산기)**           | 연산의 **결과** 및 데이터 저장을 위한 레지스터.  |
| **IR (명령 레지스터)**       | **현재 실행 중인 명령어** 코드를 저장.       |
| **MAR (기억장치 주소 레지스터)** | CPU가 접근할 **기억장치 주소**를 임시 저장.   |
| **MBR (기억장치 버퍼 레지스터)** | 기억장치와 교환할 **데이터나 명령어**를 임시 저장. |


---

#### **명령어 사이클 (Instruction Cycle) - 인출과 실행**

명령어는 **인출 단계 (Fetch Cycle)**와 **실행 단계 (Execute Cycle)**를 반복하며 처리됩니다.

- **인출 단계 (Instruction Fetch)**: 기억장치로부터 **명령어**를 읽어옵니다.
    
    - t0​: MAR←PC (다음 명령어 주소를 MAR로 보냄)
        
    - t1​: PC←PC+1, MBR←M (PC 증가, 메모리에서 명령어를 MBR로 읽음)
        
    - t2​: IR←MBR (MBR의 명령어를 IR로 전송)
        
- **실행 단계 (Execution Cycle)**: 명령어의 종류에 따라 연산을 수행합니다.
    
    - **데이터 인출 (Data Fetch)**: 명령어 실행에 필요한 **데이터**를 읽어옵니다.
        
    - **데이터 처리 (Data Process)**: ALU를 통해 산술/논리 연산을 수행합니다.
        
    - **데이터 저장 (Data Store)**: 처리 결과를 기억장치에 저장합니다.
        

---

### 3. I/O (입출력) 장치 및 시스템 구성

#### **I/O 장치 제어**

- **I/O 장치**는 CPU가 직접 접근하지 못하며 **I/O 제어기(Controller)**를 통해 CPU와 통신합니다. * **제어기**는 **상태 레지스터, 데이터 레지스터** 등을 가집니다.
    
    - **상태 레지스터**: 장치의 **현재 상태** (준비 완료/사용 중 등)를 저장.
        
    - **데이터 레지스터**: CPU와 **데이터**를 주고받는 통로 역할.
        
- **키보드 제어**: 키가 눌리면 **상태 레지스터**를 통해 CPU에 알리고, CPU가 **데이터 레지스터**의 값을 읽어갑니다. (CPU 내부 레지스터의 ${IN_RDT}$와 키보드 제어기의 $\text{IN_RDY}$를 통해 제어)
    
- **프린터 제어**: CPU가 데이터를 **프린터 데이터 레지스터**에 보내고, 프린터의 **상태 레지스터**(OUT_RDY)를 확인하여 출력 완료를 확인합니다.
    

#### **컴퓨터 시스템의 전체 구성**

- CPU, 주기억장치, 디스크/SSD 제어기, 키보드 제어기, 프린터 제어기 등이 **시스템 버스**를 통해 상호 연결되어 전체 시스템을 구성합니다.
    
    - **디스크/SSD** 등의 보조 기억장치는 보통 **블록(Block, 512Bytes)** 단위로 데이터를 전송하며, 블록은 여러 워드(Byte)로 구성됩니다.
