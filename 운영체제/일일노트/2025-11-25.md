# 스레드 동기화
## 동기화 필요성
다수의 스레드가 동시에 공유 데이터에 쓰기를 접근 시 문제 발생

## 상호배제

상호배제 위치
* 일반코드 non-critical code
* 임계구역 진입코드 entry code
* 임계구역 진출코드 exit code
* 임계구역 코드 critical code

상호배제 구현
1. 인터럽트 서비스 금지
2. 원자명령 - 상호배제를 위해 만들어진 cpu명령어

test-set

## 멀티스레드 동기화 기법
대표 기(3)
* 락방식 - 뮤텍스,스핀락
* wait-signal 방식 - 세마포

### 뮤택스
* 잠김 열림 중 한 상태를 가지는 락 변수 이용
* 한 스레드만 임계구역에 진입시킴
* 다른 스레드는 큐에 대기
* sleep-waiting lock 기법
* 단점: 임계구엳이 빨리 지나가면 안됨
