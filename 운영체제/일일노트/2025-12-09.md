## TLB
	TLB(Translation Look-aside Buffer): 가상주소 -> 물리주소 속도증가를 위한 캐시
	TLB 성능 향상: 히트율 높이기 -> 항목 늘리기(비용 부담)
	결론: 메모리 엑세스 속도 증가
	
sparse matrix(희소 정렬): 배열이 대부분 0

역 페이지 테이블 개수 - 시습템에 1개


페이지 테이블 - 역 페이지 테이블 비교
- 10개의 프로세스 4GB 사용시
- 테이블 페이지 $2^2$$^0$ -> 4MB/10개 -> 40MB
- 역 테이블 페이지 8MB
